1. Executive Summary

Present Health is a Direct Primary Care platform. Our internal tool automates the creation and management of Google Search campaigns to match clinical availability with patient demand. The tool leverages the Google Ads API for campaign provisioning, asset management (RSA), and reporting. All campaigns are created in a PAUSED state for final medical compliance review before going live.

2. Internal User Dashboard

The admin dashboard provides a centralized view for our operations team to manage marketing experiments across different clinical service areas.

Figure 1: Internal dashboard showing real-time campaign status and clinical service categories.

3. Campaign Specification & Provisioning

We define granular "Campaign Specs" (persona, budget, geography). Clicking "Go Live" triggers a sequence of API calls to create the Campaign, Ad Group, and Keyword resources.

Figure 2: Detail view for a "Virtual DPC" campaign, allowing for budget and CPA optimization.

4. Responsive Search Ad (RSA) & Compliance

Our tool generates Responsive Search Ads (RSAs) using approved medical copy. The API allows our team to sync these directly to the account after they pass our internal compliance filters.

Note on Compliance: As a healthcare provider, all ad copy is checked against a denylist of restricted terms before the API request is constructed.
Figure 3: Review interface for generated Search Ad headlines.
Figure 4: Review interface for ad descriptions.

5. Technical Architecture

  • Infrastructure: Next.js frontend deployed on Google Cloud Run.
  • API Integration: Node.js `google-ads-api` client library using OAuth2.0.
  • Data Integrity: Prisma ORM tracks Google Resource IDs to prevent duplicate provisioning.
  • Scalability: Built for internal use by a team of 5+ marketing and clinical operations staff.
